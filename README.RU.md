Клиент для **ВКонтакте**, подключается к сервисам **VK API** и предоставляет доступ к основным функциям социальной сети: лента, сообщения, профиль, друзья, сообщества. Архитектура построена на **клиент-серверном подходе**: клиент отправляет запросы, сервер VK обрабатывает их и возвращает данные.

## Возможности

- 📰 **Лента новостей** — посты друзей и сообществ
- 💬 **Сообщения** — диалоги и чаты в реальном времени
- 👤 **Профиль** — личная информация, аватар, статус
- 👥 **Друзья** — список, поиск, онлайн-статус
- 🏘️ **Сообщества** — группы и паблики
- 🔍 **Поиск** — по людям, сообществам, постам

## Архитектура

### Клиент-серверный подход (Client–Server)

Приложение работает по схеме **клиент ↔ сервер**:

1. Клиент формирует запрос к **VK API**.
2. Сервер VK обрабатывает запрос и возвращает ответ.
3. Клиент обрабатывает данные и отображает их пользователю.

Все запросы проходят через **сервисный слой**, который отвечает за авторизацию, повторные попытки и обработку ошибок.

### Обработка данных (Data Processing)

- Парсинг ответов VK API (JSON → модели)
- Фильтрация и сортировка данных
- Кэширование для офлайн-доступа
- Асинхронная загрузка изображений и медиа

### Переходы (Transition)

- Плавная навигация между экранами
- Кастомные переходы (push, modal, fade)
- Интерактивные жесты «назад»
- Синхронизация анимаций с жизненным циклом экрана

### Анимации (Animation / Animated)

- Анимированные переходы и появления элементов
- Анимация лайков, репостов, комментариев
- Пружинные и плавные кривые (spring, ease-in-out)
- Анимированные индикаторы загрузки

### NotificationCenter

Центр уведомлений для обмена событиями внутри приложения:

- Оповещения об изменениях данных
- Реакция на события авторизации
- Синхронизация состояния между модулями
- Развязка компонентов через `NotificationCenter`

### Realm

Локальное хранилище данных:

- Кэширование постов, сообщений, профилей
- Офлайн-доступ к ранее загруженным данным
- Быстрое чтение и запись
- Синхронизация с данными из VK API


### VKAPI

Слой взаимодействия с сервисами ВКонтакте:

- Авторизация через OAuth
- Запросы к методам VK API (`users.get`, `wall.get`, `messages.get`)
- Обработка ошибок и повторные попытки
- Ограничение частоты запросов (rate limiting)
